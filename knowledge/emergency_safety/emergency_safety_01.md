编一  行为经济学工具箱
第 1 章  行为经济学：人为什么不总是理性
1.1 参照点：所有判断的起点
行为经济学总开关：参照点——人不是判断「值多少」，而是判断「相对于某个参照点是好是差」。
1.2 损失厌恶：为什么「失去」比「得到」痛
损失厌恶核心数据：同等金额的损失痛苦 > 同等金额的获得快乐（常见说法 2 倍量级，非铁律）。有三个主要影响：
禀赋效应：已拥有的东西估值更高——「卖」比「买」难
处置效应：卖出盈利的股票太快，卖出亏损的股票拖太久
阿莱悖论：小概率收益 + 大概率损失时人会偏好「稳输」——「赚小亏大」
1.3 当下享乐偏误与自我控制
当下享乐偏误：现在的快乐被过度放大，未来的快乐 / 痛苦被过度折价——解释明知熬夜伤身还是熬夜。
自我限制需求：与其用意志力硬扛，不如设计让自己不必靠意志力的机制（自动转账、上锁卡）。
1.4 判断偏误：我们如何系统性地算错
高估小概率事件
低估中等概率事件
过度自信（能力高估 + 区间过窄）
1.5 助推（Nudge）：基于行为经济学的政策设计
既然人的偏误是稳定可预测的，那就可以用「助推（Nudge）」的方式设计环境，让人在不改变规则的前提下做出更好的选择。

5.2 跨域 CORS：奶茶店只接待哪些外卖平台
场景：你在 A 奶茶店点 B 店的外卖平台上的单，B 店说「对不起我们没跟这个平台合作」——这就是浏览器跨域限制。
什么算「跨」：协议（http/https）、域名、端口，三者有一个不同就算跨域
浏览器自动拦截跨域请求，但服务器之间不拦
解法：后端加 Access-Control-Allow-Origin: * 头，或用代理服务器
5.3 HTTP 缓存：奶茶店提前做好的预制品
HTTP 缓存让奶茶店提前把爆款奶茶做好放保温柜——第二次点单直接拿，不用重新做。浏览器会把图片 / JS / CSS 缓存起来，下次访问直接读本地。
5.4 微服务拆分：奶茶店分店化
微服务拆分 = 奶茶店分店化，每个分店（服务）独立运营，通过外卖平台（API）协同。
